# Briar viseme assets

Copy the Briar portrait/viseme PNGs into this folder so FastAPI can serve them from `/static/visemes`:

```powershell
Copy-Item "E:\Seagate 4TB(E Drive) DLs\E Drive Misc\BriarAI\Briar 2.0\briar_visemes\briar_*.png" .\static\visemes\
```

Expected filenames:

- `briar_idle.png`
- `briar_a.png`
- `briar_e.png`
- `briar_open.png`
- `briar_o.png`
